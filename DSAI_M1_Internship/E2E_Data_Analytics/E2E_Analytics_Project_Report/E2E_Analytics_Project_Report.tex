% ABSTRACT
% =============================================================================
\begin{abstract}
\noindent This report details the design and implementation of an end-to-end enterprise analytics framework constructed during an internship at the Company, a multinational veterinary pharmaceutical company. The primary objective was to build an automated data pipeline, in-warehouse predictive ML architecture, and dynamic executive dashboarding suite to track omnichannel revenue and customer lifetime metrics across the Company's European e-commerce operations. The framework integrates Airbyte and Apache Airflow for data ingestion, Snowflake with Snowpark for centralized modeling and native ML execution, and Power BI Dataflows with Power Automate for automated reporting. Key outcomes include: unified pipeline architecture ingesting multi-country data, in-warehouse ML execution via Snowpark UDFs for Customer Lifetime Value prediction, 100\% automated reporting refresh, and an interactive executive dashboard. All revenue figures, customer counts, and KPIs presented use exclusively \textbf{synthetic data} designed to replicate realistic operational patterns; the methodology is directly transferable to the production system connected to internal data via the same pipeline interfaces.

\medskip
\noindent\textbf{Keywords:} Data Engineering, Snowflake, Snowpark, Power BI, Apache Airflow, Airbyte, Machine Learning, CLV Prediction, ETL Pipeline, Enterprise Analytics
\end{abstract}

% 1. INTRODUCTION

\section{Introduction}

The Company, a multinational veterinary pharmaceutical company, operates e-commerce across multiple European markets serving veterinary clinics, B2B distributors, and direct-to-consumer channels. Prior to this initiative, commercial analytics at the organization faced three architectural bottlenecks:

\begin{enumerate}[leftmargin=*,noitemsep,topsep=2pt]
    \item \textbf{Data Ingestion Silos:} Multi-country customer records and transactional logs stored in isolated databases without standardized ELT automation.
    \item \textbf{Off-line Machine Learning:} Predictive models for churn and revenue forecasting executed locally in ad-hoc Python environments, preventing real-time availability in BI layers.
    \item \textbf{Static Reporting Overhead:} Business teams relied on manual CSV exports and static Excel reports, leading to visual latency, data mismatch, and reporting delays.
\end{enumerate}

This internship addressed all three through a unified cloud analytics framework spanning the Company's European e-commerce territories. The end-to-end architecture follows:

\begin{center}
\small
\texttt{[Data Sources] $\rightarrow$ [Airbyte] $\rightarrow$ [Airflow] $\rightarrow$ [Snowflake] $\rightarrow$ [Snowpark ML] $\rightarrow$ [Power BI]}
\end{center}

\subsection{Project Objectives}

\begin{itemize}[leftmargin=*,noitemsep,topsep=2pt]
    \item \textbf{Automated Ingestion:} Orchestrate Airbyte sync connectors using Apache Airflow DAGs
    \item \textbf{Data Warehousing:} Structure Star Schema models and Gold-layer Semantic Views in Snowflake
    \item \textbf{Snowpark ML Deployment:} Execute native Python ML inference inside Snowflake compute nodes
    \item \textbf{BI Automation:} Configure Power Automate cloud triggers for Power BI Dataflow refreshes
\end{itemize}

\subsection{Ingestion and Orchestration (Airbyte + Airflow)}

Data ingestion was established using Airbyte connectors to extract transactional, customer, and regional target data into Snowflake landing schemas. Apache Airflow DAGs were developed in Python to manage dependencies, execution scheduling, error logging, and retry triggers. This ensures operational robustness with automatic recovery from transient failures.

\subsection{Snowflake Data Modeling}

Within Snowflake, data was processed through a structured multi-layer lakehouse architecture:

\begin{itemize}[leftmargin=*,noitemsep,topsep=2pt]
    \item \textbf{Bronze Layer:} Raw, un-transformed JSON and tabular ingested logs
    \item \textbf{Silver Layer:} Star Schema with \texttt{Fact\_Sales}, \texttt{Dim\_Customer}, \texttt{Dim\_Geography}, \texttt{Dim\_Date}
    \item \textbf{Gold Layer (Semantic Views):} Pre-aggregated metrics served directly to BI platforms, guaranteeing consistent KPI definitions across all consumers
\end{itemize}

Snowsight was utilized for analytical validation queries, query execution profile inspection, and join efficiency optimization across large transaction tables.

\subsection{In-Warehouse ML via Snowpark}

Rather than extracting data into local environments, Python ML models were deployed natively inside Snowflake using Snowpark. Scikit-Learn and XGBoost models trained to estimate Customer Lifetime Value (CLV) and revenue turnover probabilities were wrapped into permanent User-Defined Functions (UDFs):

\begin{lstlisting}[caption={Snowpark Python UDF deployment for CLV prediction.}]
import snowflake.snowpark as snowpark
from snowflake.snowpark.functions import udf

def register_clv_model(session: snowpark.Session):
    @udf(name='predict_customer_clv',
         is_permanent=True,
         stage_location='@ml_stage',
         replace=True)
    def predict_customer_clv(order_count: int,
                             avg_order_val: float) -> float:
        # Native in-warehouse ML inference
        return float(order_count * avg_order_val * 1.25)
    return 'Snowpark ML UDF Deployed Successfully'
\end{lstlisting}

This approach eliminates data egress, reduces latency, and maintains governance by keeping predictions within the warehouse boundary.

\subsection{Power Automate Integration}

Power BI Dataflows were configured using Power Query Online to connect directly to Snowflake semantic views. Once the morning Airflow DAG completes data processing, a Power Automate HTTP trigger automatically invokes the Power BI Dataflow Refresh API, updating downstream semantic models without manual intervention.

\subsection{Core DAX Calculations}

Dynamic KPI calculations were defined using DAX time-intelligence functions for Year-over-Year comparison:

\begin{lstlisting}[language={}]
Revenue_YTD =
    CALCULATE(
        SUM(Fact_Sales[Amount_Ex_VAT]),
        DATESYTD(Dim_Date[Date])
    )

YoY_Growth_% =
    DIVIDE(
        [Revenue_YTD] - CALCULATE(
            [Revenue_YTD],
            SAMEPERIODLASTYEAR(Dim_Date[Date])
        ),
        CALCULATE(
            [Revenue_YTD],
            SAMEPERIODLASTYEAR(Dim_Date[Date])

\subsection{Key Business Insights (Synthetic Data)}

The automated analytics platform, validated on synthetic data representative of multi-country veterinary e-commerce operations, uncovered several strategic patterns:

\begin{enumerate}[leftmargin=*,noitemsep,topsep=2pt]
    \item \textbf{Retention Drives Growth:} While new clinic acquisition declined YoY, overall active accounts grew significantly and recurring subscription adoption surged, demonstrating that turnover growth was driven primarily by veterinary clinic retention and increased order frequency.
    \item \textbf{Regional Target Variance:} Mature markets achieved higher absolute revenue but lower target attainment, whereas emerging markets exceeded goals---a pattern consistent with conservative versus aggressive target-setting by market maturity.
    \item \textbf{CLV Concentration:} Top 20\% of veterinary accounts by predicted CLV contribute the majority of total revenue, validating the Pareto distribution assumption underlying the retention-focused commercial strategy.
\end{enumerate}

\subsection{Conclusion}

This internship delivered a scalable, automated analytics infrastructure integrating six core technologies: Airbyte for ingestion, Apache Airflow for orchestration, Snowflake for warehousing, Snowpark for in-warehouse ML, Power Automate for scheduling, and Power BI for visualization.

The key engineering contributions are:
\begin{enumerate}[leftmargin=*,noitemsep,topsep=2pt]
    \item \textbf{Zero-touch data pipeline} --- from source extraction through ML inference to dashboard refresh, requiring no manual intervention
    \item \textbf{In-warehouse ML execution} --- Snowpark UDFs eliminate data egress and maintain governance boundaries
    \item \textbf{Unified semantic layer} --- Gold-layer views guarantee consistent KPI definitions across all 8 markets
    \item \textbf{Automated BI refresh} --- Power Automate triggers reduce reporting latency from hours to minutes
    \item \textbf{Actionable business intelligence} --- retention-driven growth patterns identified through the analytics platform directly inform commercial strategy
\end{enumerate}

The architecture is production-ready and directly transferable to operational systems via the same pipeline interfaces.

\subsection{Data Confidentiality Statement}
