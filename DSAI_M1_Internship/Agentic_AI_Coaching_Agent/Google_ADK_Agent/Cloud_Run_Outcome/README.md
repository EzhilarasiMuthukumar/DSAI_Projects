# Cloud Run Outcome (Proof of Concept)

This folder holds a lightweight artifact from a proof-of-concept Cloud Run deployment
of the SPIN Coach agent, done as part of this MSc internship project to validate that
the agent could be containerized and served via Google Cloud Run.

- `How many pets does your clinic treat monthly_.json` — a sample exported session
  showing one scripted coaching interaction and its evaluation score, used to confirm
  the deployed agent behaved the same as the local version.

Deployment screenshots and billing details were intentionally left out of this public
repo since they only showed internal tooling, not project results.
